# Roadmap

## Milestone 1

- stable CLI for local analysis
- JSON and CSV schema versioning
- richer `httpx` and `nuclei` parsing coverage
- fixture-based tests

## Milestone 2

- `naabu` and port scan imports
- screenshot and TLS metadata correlation
- diff mode between two recon runs
- ignore rules and analyst labels

## Milestone 3

- plugin system for custom enrichers
- export adapters for notes and reporting pipelines
- lightweight TUI or web read-only viewer

## Milestone 4

- team handoff bundles
- evidence attachment conventions
- optional LLM-assisted report drafting from structured outputs

LLM features stay optional. The core product has to remain useful without them.
