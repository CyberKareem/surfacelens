# Changelog

- introduced confidence and priority tiers
- added HTML dashboard export
- added `nmap` and TLS-style evidence ingestion

- added snapshot diff command

## 0.1.0 - 2026-03-27

- support for `subfinder`, `httpx`, `katana`, and `nuclei`
- Markdown, JSON, and CSV exports
